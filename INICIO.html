CONSTRUIR

Una carpeta nueva. Un negocio propio.

npm run start

El generador incluye dashboard, API, base de datos y documentación. El asistente instala dependencias, prepara D1 local y compila. Publica con npm run deploy:guided desde el proyecto nuevo. Para trabajar con clientes reales, genera con --mode production y completa identidad, credenciales y aceptación antes de activarlo.
