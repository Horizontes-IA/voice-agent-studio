## 2. Reúne información

Tres servicios con duración, buffer y precio. Profesionales y especialidades. Recursos disponibles, zona horaria y moneda. Horarios, excepciones, política de cambios y cinco preguntas frecuentes. Persona que aprueba las respuestas y atiende solicitudes.

## 3. Construye

- Copia el preset correspondiente a tu archivo JSON.
- Usa un slug propio y una carpeta nueva. `npm run start -- --config ./mi-negocio.json` guía la instalación.
- Comprueba el arranque, los secretos privados, D1 local y la compilación. Para HTTPS usa `npm run deploy:guided`.
- Entra al dashboard y confirma que tu catálogo y conocimiento aparecen.
- No edites una DB ajena ni pegues claves en el chat del taller.
