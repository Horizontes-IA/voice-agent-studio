# Demo de 8 minutos

**Preparación:** despliegue propio con datos sintéticos, sesión de admin iniciada fuera de la grabación, micrófono comprobado y escenario alternativo si falla el proveedor. Nunca muestres .dev.vars, cookies ni la pantalla de credenciales.

**0:00–1:00 · El proceso.** “Hoy su equipo hace X. Vamos a mostrar cómo una solicitud termina registrada y dónde puede revisar el resultado”. Pregunta si el escenario representa un caso habitual.

**1:00–3:30 · Conversación.** Consulta un servicio, solicita una fecha, elige una opción, pide un cambio de horario y confirma una sola vez. Usa el servidor como fuente de disponibilidad. Abre la agenda para mostrar la acción guardada.

**3:30–4:30 · Control del negocio.** Muestra cómo editar una respuesta en conocimiento, guardar un borrador y publicarlo. Explica quién debería aprobar ese contenido en la implementación real.

**4:30–5:30 · Caso propio del sector.** Estética: reserva el paquete completo y comprueba el tiempo bloqueado. Taller: consulta OT-1001 con el cliente 1, cambia su nota desde administración y repite la consulta. Dental: solicita un profesional incompatible y muestra cómo el sistema conserva las reglas.

**5:30–6:30 · Excepción.** Pide hablar con una persona o solicita algo fuera del catálogo. Muestra la solicitud pendiente y explica quién la atendería. No lo describas como transferencia de llamada.

**6:30–8:00 · Piloto.** Resume qué quedó demostrado, qué integración necesita el negocio y qué falta para usar datos reales. Propón una segunda reunión para acordar alcance y aceptación; no prometas ahorros sin medir la situación actual.

## Preguntas útiles de cierre

- ¿Qué caso falta para que este flujo les resulte útil?
- ¿Qué sistema debe seguir siendo la fuente oficial?
- ¿Quién probaría el piloto y aprobaría sus resultados?
- ¿Podemos medir una semana de volumen antes de definir capacidad y costos?

**Seguimiento preparado:** enviar resumen de lo demostrado, alcance propuesto, pendientes y siguiente reunión. El alumno decide a quién contactar y autoriza cada envío; este kit no envía mensajes por su cuenta.
